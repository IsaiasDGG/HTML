Primera parte: Lista de definición (rellenar los <dd>)

Escribe una definición clara y breve para cada elemento.

<title>
Etiqueta que permite añadir un título al documento HTML creado, modifica lo que dice en la pestaña del navegador.
<meta>
Etiqueta que hace referencia a los metadatos que contendrá el documento HTML, es una etiqueta especial y posee diversos usos, entre los más destacados, está el chartset, es decir asignar el tipo de codigo que se usará.
<strong>
es similar a la etiqueta <b>, ya que visualmente ennegrese el contenido, pero tambien modifica semanticamente el significado, indicando a los buscadores que su contenido se debe considerar como keywords
<ul>, <ol> y <li>
Las tres etiquetas se usan para crear listas desordenadas u ordenadas, las primeras usan la etiqueta <ul> como unorderer list, y la etiqueta <li> las lista con viñetas sin enumeración. Por otra parte la etiqueta <ol> conocida como orderer list, genera una lista ordenada, y la etiqueta <li> asigna numeros consecutivos a la lista que se genere.
<div>
La presente etiqueta ayuda a dividir la estructura del documento, cuya relevancia destaca al momento de usar estilos o css. ya que permite separar o diferenciar las modificaciones de estilo que se buscan realizar.
<blockquote>
esta etiqueta permite agregar sangria al lado izquierdo y derecho del texto
<pre>
permite ingresar texto preformateado, es decir el navegador mostrará el texto con el formato que se usa en el documento de texto usado.
